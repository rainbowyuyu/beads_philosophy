# 从一颗拼豆，到物理学的尺度

这份资料接着影片最后的问题往下走：拼豆有豆子，数字图像有像素，三维方块有体素。那么，自然也有一套最小积木吗？

先把两件事分开：**我们用多大的格子表示世界**，和**世界本身怎样变化**。

## 1. 前半程：我们选择的单位

| 对象 | 这里的“一个”是什么 | 改小之后会怎样 |
| --- | --- | --- |
| 拼豆图纸 | 一颗豆子、一个放置位置 | 可以表现更细的轮廓，需要更多材料与位置 |
| 位图 | 一个像素的颜色记录 | 重新采样更高分辨率的原图，才可能获得新细节；把旧像素分成四格不会自动生出细节 |
| Minecraft / 体素 | 一个格位及其方块状态 | 同一边长内各轴格数翻倍，稠密格位数变成八倍 |
| 点云 | 一次采样得到的三维位置 | 点更多不等于更准确；位置误差、遮挡和配准仍然重要 |
| FDM 打印 | 一层的高度、一条沉积路径及其宽度 | 层高影响 Z 方向的离散；喷嘴、线宽与运动影响 XY 方向。材料不是按完整小立方体搬进去的 |

这些单位来自材料、记录方法和制造选择。它们让我们能做出一只兔子，也提醒我们：**表示方法的颗粒，不自动等于自然的颗粒。**

## 2. 普朗克当时在问什么

1900 年前后，普朗克研究的是热辐射。炉子升温会发红，更热时颜色和亮度又会变化。把不同波长处的辐射强度测出来，就得到一条光谱曲线。

理想黑体给了物理学一个干净的问题：在热平衡下，曲线的形状怎样随温度变化？当时已有实验数据与不同理论，普朗克要解释整条曲线。

他在推导中引入大小为 **hν** 的能量元，处理物质振子的能量统计。后来，量子理论发展出了离散能级等结果。1905 年爱因斯坦提出光量子假说，是另一项关键进展；不要把它们都缩成“普朗克一次性发明了全部量子力学”。

### 光谱怎样连到“一份一份”

对于频率固定为 ν 的振子，普朗克推导中的能量以 hν 为步长计数。现代量子谐振子的能级是：

```text
E_n = (n + 1/2) hν，n = 0, 1, 2, …
相邻能级差：ΔE = hν
```

这不是说任何能量都只能取同一个固定步长。步长随频率变化，量子体系也可能具有连续谱。是否离散，要看具体系统和物理量。

## 3. 亲手画一条黑体光谱

在仓库根目录运行以下命令，不需要下载实验数据。下文 `python` 指根 README 中安装好的虚拟环境解释器；Windows 可写为 `.\.venv\Scripts\python.exe`，macOS / Linux 为 `.venv/bin/python`。

```bash
python quantum/blackbody.py --out outputs/quantum
```

得到 `blackbody.svg`、`blackbody.csv` 与 `summary.json`。图中比较 3000、4500、6000 K 的理论光谱，横轴是波长，纵轴是单位波长的谱辐亮度，三条曲线共用同一条纵轴。较热曲线的峰值向短波方向移动，强度也更大。

计算采用普朗克定律：

```text
B_λ(T) = (2hc² / λ⁵) / [exp(hc / (λk_B T)) - 1]
```

λ 在公式中使用米；CSV 与图表按微米显示波长。CSV 中的谱辐亮度单位为 W·m⁻²·sr⁻¹·μm⁻¹；图表为便于阅读使用 MW·m⁻²·sr⁻¹·μm⁻¹，即把 CSV 数值除以 10⁶。曲线是公式计算结果，**不是新测得的实验数据**。按波长与按频率画出的谱密度不同，不能简单对峰值作 ν = c/λ 的替换。

## 4. 普朗克长度与普朗克时间

把约化普朗克常数 ℏ、引力常数 G、光速 c 组合起来，可以得到自然尺度：

```text
ℓ_P = √(ℏG/c³) ≈ 1.616255 × 10⁻³⁵ m
t_P = ℓ_P/c   ≈ 5.391247 × 10⁻⁴⁴ s
```

这里的数值采用 NIST 的 2022 CODATA 推荐值；G 的测量不确定度使这些数值也带有不确定度。

这些尺度提示我们，量子效应和引力可能需要放在同一个理论框架里讨论。**目前没有实验确认它们就是空间、时间不可再分的最小单位。** 它们不是一台显微镜已经拍到的“宇宙像素”或“宇宙帧”。

不同量子引力方案对几何和时空结构有不同描述。有的理论出现某些几何算符的离散谱，这也不能直接翻译成宇宙是一张固定立方网格。

## 5. 带着三个问题看完这段旅程

1. 把一张像素图放大十倍，为什么轮廓可以更大，却没有更多原始细节？
2. 打印机一层层工作，为什么喷头仍能沿连续路径运动？
3. 某个量子体系具有离散能级，为什么还不足以证明空间也由小格子组成？

同一只兔子能被写成颜色表、方块表、三角网格和打印路径。每种表示都打开了一种操作世界的方法。继续追问到物理学，问题就从“怎样拼出来”，变成了“自然允许怎样变化”。这一步的精彩，在于我们知道了什么，也清楚还要寻找什么。
