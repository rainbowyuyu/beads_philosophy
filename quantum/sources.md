## 常用说法的准确版本

| 容易混淆的说法 | 更准确的表达 |
| --- | --- |
| 世界像拼豆，所以宇宙也是像素化的 | 拼豆是类比；表示世界的离散方式不能证明时空离散 |
| 能量永远只有一个固定的最小份额 | 具体系统的能谱可能离散或连续；hν 随频率 ν 变化 |
| 1900 年普朗克已经提出完整光子理论 | 普朗克引入能量元处理热辐射统计；1905 年爱因斯坦的光量子假说另有关键贡献 |
| 普朗克长度就是已证实的最小距离 | 它是由基本常数组成的自然尺度，尚未被证明是最小空间单位 |
| 打印层越薄，所有方向都同样精确 | 层高主要影响 Z 向，XY 还受喷嘴、线宽、路径和机械运动影响 |
